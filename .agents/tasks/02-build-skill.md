# 任务 02：编写 XPKG-creator Skill

## 任务目标
产出一个可直接复用的 agent skill，帮助贡献者稳定编写、测试并提交 XPKG 包。

## 实现内容
- 新建 `.agents/skills/xpkg-creator/SKILL.md`。
- 给出包描述文件建议结构（字段、示例、注意事项）。
- 说明 hook 分工：
  - `install`：获取/解压/安装主体文件，避免污染系统路径。
  - `config`：在 XVM/subOS 体系内做注册、映射与版本隔离。
- 强调优先使用预构建二进制，减少编译负担和依赖漂移。
- 添加 XLinks 项目链接与安装入口说明。
- 补充完整测试流程与 PR 提交流程模板。

## 验收标准
- skill 文档可独立阅读执行。
- 安装与配置职责边界清晰、可操作。
- 测试流程覆盖安装、搜索、命令可用性、卸载清理。
- PR 要求包括变更说明、平台验证、系统改动清单。

## 测试与检查
- 人工审阅 skill 章节是否齐全、顺序合理。
- 核对是否明确“最小系统改动 + XVM 映射”原则。
